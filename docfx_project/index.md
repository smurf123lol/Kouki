# Kouki — платформа для оркестрации команд

Kouki — это набор библиотек для создания автоматизированных систем, AI-агентов и голосовых ассистентов.

## Основные модули

- **Kouki.Mugura** — ядро оркестрации команд.
- **Shimi** — абстракции и адаптеры для работы с окружением.
- **Kagedama** — примеры использования.

## Быстрый старт

Создайте хендлер с атрибутом `[Command]`, зарегистрируйте через `AddMugura` и вызывайте `IRouter.RouteAsync`. Подробнее в руководстве.
