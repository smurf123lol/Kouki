# Примеры использования: Kagedama

Этот раздел содержит готовые сценарии использования Kouki в реальных приложениях.

## Проекты

- [Kagedama.API](api/Kagedama.api) — MCP-сервер для AI-агентов. Принимает JSON-RPC запросы и выполняет команды через `IRouter`.

## Как использовать

Каждый проект является самостоятельным приложением, которое использует библиотеки Mugura и Shimi. Вы можете запускать их локально или использовать как основу для своих решений.
