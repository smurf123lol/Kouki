# Изменения

Проект развивается этапами; ниже — что уже есть в коде. Подробности по решениям и найденным
дефектам — в `notes-updated/` рабочей папки (вне репозитория) и в `docfx_project/docs/`.

## v0.6 — MVP (23–26.10.2026)

### M1. Приём задач и хранение

- `Kouki.Kagedama.Contracts` — интерфейсы данных без зависимостей; `Kouki.Kagedama.Data` —
  SQLite: задачи, журнал распознавания, журнал действий, состояние.
- Приём фразы (`TaskIntakeService`): классификация → команда → запись; транзакции через
  `IUnitOfWork`, один создатель задачи (`TaskFactory`), единые `TaskSources`/`TaskStatuses`.
- `Kouki.Yasabi` — правила интентов, журнал вердиктов, маршрут «интент → команда».
- `Kagedama.api` — HTTP API (`/api/intake`, `/api/tasks`, `/api/actions`, `/api/classifications`,
  `/api/context`), SQLite, bearer-токен (fail-closed), дашборд.

### M2. Telegram-бот

- `Kouki.Kagedama.Bot` — long polling, ответы по статусу задачи и результату команды.

### M3. MCP и плагин DSH

- `Kagedama.mcp` — MCP-сервер (stdio): инструменты `kouki_*` для задач, журналов и контекста.
- `dsh-kouki` — плагин DeepSeek Harness: MCP-клиент, ленивое подключение, инструменты в чате.

### M4. Голос и станция

- `Kouki.Un` — распознавание речи на sherpa-onnx (whisper), включается флагом
  `-p:KoukiEnableSherpa=true`; адаптер под контракт `ISpeechTranscriber`.
- `POST /api/voice` — WAV PCM16 16 кГц моно → текст → задача; сессии записи и вопроса
  (`intent=add_task|ask`), аудио хранится до разметки, ретеншн настраивается.
- `kouki-station` — отдельный репозиторий прошивки (ESP-IDF 5.5.1, ESP32-S3-Touch-LCD-1.85C):
  кнопка «Записать»/«Спросить», кириллица на экране, опциональное кодовое слово, усиление
  микрофона и порог речи, https через crt bundle.

### M5. Дашборд и наблюдение

- Дашборд: задачи, разбор, приём, действия, сравнение роутеров, точечное автообновление
  (не сбрасывает ввод), журнал HTTP-запросов.

### Ревью и инфраструктура

- Исправлены находки ревью: композиция хостов через `KoukiHosting`, авторизация fail-closed,
  устойчивость MCP, контракт ASR, единый словарь исходов, журналы и разметка — командами,
  подтверждение опасных команд (`RequiresConfirmation`), пометка «не по-русски» в мете задачи.
- CI: сборка решения, сборка и тесты с распознаванием, тесты плагина; общий
  `Directory.Build.props`, `global.json`, `.editorconfig`.
- Правила для людей и агентов: `AGENTS.md`, `CONTRIBUTING.md`.
- Тесты: 141 (свой раннер `_scratch/testrun`, `[Theory]` не исполняется).
